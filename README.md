# Networking & Cybersecurity Portfolio

## About This Portfolio

This repository showcases my hands-on learning and practical skills in **computer networking, network traffic analysis, attack detection, IP addressing, subnetting, and Linux network troubleshooting**.

The portfolio contains four practical projects built to strengthen my networking fundamentals and develop skills relevant to cybersecurity and network security roles.

## Projects

### 1. Cisco Packet Tracer – Company Network Infrastructure
Designed and configured a small company network with three departments: HR, Finance, and IT.

- Created a network topology using routers, switches, and end devices.
- Connected devices and configured network communication.
- Tested connectivity between devices.

**Tools:** Cisco Packet Tracer

### 2. Wireshark – Packet Analysis & Attack Detection
Captured and analyzed network traffic to understand communication patterns and investigate suspicious activities.

- Analyzed DNS, TCP, ARP, and ICMP traffic.
- Investigated port scanning, DDoS-related traffic patterns, and ARP spoofing.
- Practiced identifying suspicious network behavior through packet analysis.

**Tools:** Wireshark, Nmap, Kali Linux

### 3. IP Addressing & Subnetting
Designed an IP addressing plan for a small company network and configured IP addresses manually.

- Practiced IPv4 addressing and subnet mask calculations.
- Learned CIDR notation, network addresses, broadcast addresses, and usable host ranges.
- Configured IP addresses and default gateways.
- Verified network connectivity using ping tests.

**Tools:** Cisco Packet Tracer

### 4. Linux Networking & Troubleshooting
Practiced Linux networking commands to inspect network configuration, test connectivity, and troubleshoot common network issues.

- Inspected network interfaces and routing tables.
- Tested connectivity and DNS resolution.
- Checked listening ports and network interface statistics.
- Practiced basic network troubleshooting in Kali Linux.

**Tools:** Kali Linux, Linux networking commands

## Skills Demonstrated

- Network topology design and device configuration
- IPv4 addressing and subnetting
- Packet capture and protocol analysis
- Basic network attack detection
- Linux networking and troubleshooting
- Connectivity testing and network diagnostics
