# Packet Analysis & Attack Detection

## Project Overview
This project focuses on capturing and analyzing network traffic using Wireshark to understand network protocols and investigate suspicious activity. I performed practical network security exercises involving port scanning, DoS-related traffic analysis, and ARP spoofing investigation in a lab environment.

The objective was to understand how different types of network activity appear in packet captures and how network evidence can be used to investigate potential security incidents.

## Objectives
- Capture and inspect network packets using Wireshark.
- Understand DNS, TCP , UDP , ARP, and ICMP traffic.
- Investigate port scanning behavior.
- Analyze traffic patterns associated with Denial-of-Service (DoS) activity.
- Examine ARP traffic for potential spoofing indicators.
- Document findings and consider possible false positives.

## Practical Work

### 1. Port Scan Analysis
Performed a port scanning exercise and examined the resulting TCP traffic in Wireshark. Investigated connection attempts, TCP flags, destination ports, and communication patterns to understand how port scanning can be identified.

### 2. DoS Traffic Analysis
Conducted a DoS-related lab exercise and analyzed network traffic in Wireshark. Examined packet rates, traffic volume, and communication patterns to understand indicators of potentially disruptive traffic.

### 3. ARP Spoofing Investigation
Used arpspoof in a lab scenario and inspected ARP packets and IP-to-MAC address mappings. The observed traffic appeared normal, and I did not identify conclusive evidence of ARP spoofing in the capture. This highlighted the importance of validating findings rather than assuming an attack was successful.
